# CITRA

AI Search Intelligence dashboard. CITRA models how answer engines see a brand, surfaces citations and competitors, evaluates entity health, and turns visibility gaps into actionable recommendations.

## Features

- AI visibility overview across simulated answer engines
- Query intelligence and buyer-query simulation
- Competitor intelligence across visibility signals
- Citation explorer and source diversity analysis
- Entity health for organization, product, service, author, location, FAQ, and reviews
- AI action plan with prioritized visibility opportunities
- Guided site analysis workflow

## Tech Stack

- React / TypeScript
- Vite
- TanStack Router
- Tailwind-style custom CSS
- Bun

## Run locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Project structure

- `src/routes` - application screens and routes
- `src/lib` - CITRA data, session helpers, utilities, and error handling
- `src/hooks` - reusable React hooks
- `public` - static assets
